# A White Bug 源码讲解顺序

这个目录把原来的 `BugGame.cpp` 拆成了更适合讲解的小模块。

现在已经整理成标准 `.h/.cpp` 结构：`Game.h` 放声明和数据结构，各个 `.cpp` 分别编译。这样更符合正常课程项目的组织方式。

建议视频或答辩时按这个顺序介绍：

1. `Game.h`
   公共头文件，包含游戏常量、数据结构、全局状态声明和函数声明。

2. `Levels.cpp` 和 `Levels/`
   所有关卡配置。每一关一个 `.cpp` 文件，现在只保存“同色点配对关系”，并用注释说明关卡设计意图。

3. `Layout.cpp`
   窗口、棋盘、端点和特殊关卡几何位置。第五到第七关的窗口缩放机制主要看这里。

4. `GeometryAndCollision.cpp`
   几何算法、线段交叉、墙体碰撞、最终涂白判定。

5. `RulesAndFlow.cpp`
   通关规则、路径记录、非法线淡出、关卡切换、顺序解锁。

6. `Input.cpp`
   鼠标按下、移动、松开时如何开始画线、追加点、结束判定。

7. `Graphics.cpp` 和 `RenderScene.cpp`
   GDI 绘图、双缓冲、圆点、线条、隔板、选关界面和最终文字显示。

8. `SystemProgress.cpp`
   文件名改色、进度保存、通关后重置进度。

9. `WinMain.cpp`
    Windows 程序入口、窗口创建和消息处理。
